## Research

### VLA-CoT: Chain-of-Thought Guided Vision-Language-Action for Robotic Cable Routing
**IHCI 2026 · Accepted, oral presentation · Ningbo, China**

Designed a VLA framework that breaks cable routing into five planning phases before predicting 7-DoF control actions. Evaluated interchangeable vision and language encoders under a shared training setup on Berkeley Cable Routing from Open X-Embodiment. The reported results include an **82.2% WTA-10 lift** and approximately **0.0148 MAE**. I’m extending this work toward deployment on a custom-built 4-DoF manipulator.

### Mind-Wander: Dual-Stream EEG Framework for Attentional State Inference
**IEEE AI-SIIS 2026 · Accepted · Hyderabad**

Built a dual-stream model that combines temporal EEG signals with spectral bandpower features through cross-attention. It achieved **96.9% accuracy** and **97.2% F1** on the BCIT Mind-Wandering dataset, evaluated with a strict leave-one-subject-out protocol across 22,271 windows from 12 subjects.
